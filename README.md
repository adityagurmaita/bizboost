# Duggu Sweets

![Project](https://img.shields.io/badge/project-bizboost-d89539) ![Status](https://img.shields.io/badge/status-demo-blue)

**HTML · CSS · JavaScript**

A responsive sweets-and-snacks storefront demo with a working local shopping bag.

## ✨ Features
- Product grid with local SVG menu illustrations - no missing-image paths.
- Search and category filters (sweets / snacks).
- Shopping bag with quantity controls, an estimated total and a transparent demo checkout preview; the bag persists in localStorage.
- Rule-based occasion recommendations and a dark/light theme toggle.
- Mobile-first responsive layout.

## 🚀 Run locally
Open `index.html` in a browser, or serve the repository with `python3 -m http.server 8080`. No dependencies or build step are required.

## 📌 Limits
This is a frontend demo, not a real ordering or payment system. Recommendations use fixed rules, not an AI service. The checkout only previews an order; no payment, delivery or real order is created. Product artwork is original illustration, not food photography.
