# Duggu Sweets

![Project](https://img.shields.io/badge/bizboost-d89539) ![Status](https://img.shields.io/badge/status-demo-blue)

**HTML · CSS · JavaScript**

A static sweets-and-snacks storefront demo built with HTML, CSS and JavaScript.

## ✨ Features
- Product search and a dark-mode toggle.
- A rotating sweet-of-the-day suggestion.
- Rule-based mood recommendations.
- Random demo rewards and token numbers.

## 🚀 Run locally
Open `index.html` in a browser, or serve the repository with `python3 -m http.server 8080`. No dependencies or build step are required.

## 📁 Files
`index.html` contains the page, `style.css` the styling, and `script.js` the interactions.

## 📌 Limits
This is a frontend demo, not a real ordering or payment system. Recommendations use fixed rules, not an AI service. Rewards and token numbers do not create an order or entitlement. Some product image paths currently refer to an absent `images/` directory; those need replacement with the intended product photos before deployment.
